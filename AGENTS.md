# AGENTS

Правила работы агента с репозиторием bytetap.

## Проект

- Личный независимый open source проект (MIT) на GitHub владельца. Не упоминать и не привязывать к конкретным ЛИС, лабораториям, заказчикам и их данным.
- Источник требований — `docs/requirements.md`, идентификаторы требований (FR-, NFR-, T-) указывать в коммитах и PR, когда изменение их реализует.
- Порядок работ — этапы M1–M6 из `docs/requirements.md`.

## Код

- Ядро захвата — Rust crate без зависимости от Tauri; оболочка — Tauri v2, интерфейс — Vue 3 + TypeScript.
- Перед сдачей: `cargo fmt --check`, `cargo clippy -- -D warnings`, `cargo test`, сборка фронтенда.
- Не коммитить журналы реальных сессий (`*.jsonl` с данными приборов): они могут содержать персональные данные пациентов. Тестовые журналы — только синтетические.

## Markdown

- Не использовать `---` как разделитель разделов.
- Абзац и пункт списка — одной строкой, без ручного переноса.
