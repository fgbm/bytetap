# U1 — нативный интерфейс (egui)

Цель этапа — паритет с UI v2 Tauri-версии и выпуск v0.2.0 без WebView2: тот же интерфейс и те же функции, что в v0.1.0, но приложение — один exe на egui, eframe и wgpu, который запускается на машинах со старым или отсутствующим WebView2. Решение и его последствия — [ADR 0003](/dev/adr/0003-native-ui). Функции ядра, формат журнала и CLI не меняются.

## Эталон

- Визуал и поведение — UI v2 Tauri-версии: раздел «UI v2» [этапа M3](/dev/stages/M3), код `app/src/**` в `main`, снимки `/tmp/opencode/ui-v2/` (сценарии, шаги трёх режимов, запись, ASTM, HEX, прокрутка), [дизайн-система](/dev/design) и ручной смоук в [тестировании](/dev/testing).
- Техника — прототип в ветке `proto/egui` (crate `bytetap-egui`): wgpu на DX12 с WARP, шрифты IBM Plex из TTF, иконки Lucide через resvg, лента на `show_rows`, снимки `egui_kittest`.
- Отступления от UI v2, которых требует egui (ADR 0003): текст без ClearType смягчается кеглем, копирование из ленты — через контекстное меню строки. Остальное — как в Tauri-версии; каждое новое отступление согласует владелец.

## Решения этапа

- Работа идёт в ветке `native-ui`; `main` остаётся на Tauri и получает исправления до паритета, исправления UI v2 из `main` переносятся в U1.
- Crate приложения — `crates/bytetap-app` (bin `bytetap`, exe `bytetap.exe`). Он зависит от `bytetap-core` напрямую: управление — вызовы `bytetap-core::session`, события — подписка `tokio::sync::broadcast` в кольцевой буфер интерфейса на 10 000 фрагментов. Мост Tauri, команды и `Channel` не переносятся.
- Runtime `tokio` живёт в отдельном потоке приложения; поток окна никогда не ждёт ввод-вывод: долгие операции (список портов, индекс журнала, выбор папки) возвращают результат в интерфейс через канал и `request_repaint`.
- Перерисовка — только по событию: в простое кадров нет; во время записи `request_repaint` вызывается не чаще ~30 раз в секунду, сколько бы фрагментов ни пришло.
- Токены остаются в `design/tokens.css` — единый источник для сайта документации и приложения; `build.rs` генерирует из CSS-переменных Rust-константы для светлой и тёмной темы. Ручных копий цветов в Rust нет.
- Логика моста, не зависящая от Tauri (`list_recent_journals`, индекс журнала из `app/src-tauri/src/journal.rs`, `diag.rs`, проверка папки журналов, добавление `note`), переносится в ядро, если она нужна CLI, иначе в crate приложения, вместе с её тестами.
- Настройки и профили — JSON в `%APPDATA%\bytetap` (на Linux — каталог конфигурации пользователя); испорченный файл копируется рядом как `settings.corrupt-<дата>.json`, приложение стартует с умолчаниями и показывает предупреждение — как в Tauri-версии.
- Один экземпляр приложения не обязателен: два окна с разными папками журналов допустимы, как и в v0.1.0.

## Критерии приёмки

Шаг 1 — оболочка:

- [x] U1-AC1 (NFR-2, NFR-3). `cargo build --release -p bytetap-app` даёт `bytetap.exe`, который запускается двойным щелчком без консольного окна; рядом не нужно ни одного файла, в зависимостях exe (`dumpbin /dependents`) только системные DLL Windows — нет WebView2Loader, .NET и VC++ Redistributable.
- [x] U1-AC2 (NFR-3). Отрисовка — wgpu на DX12; при отсутствии аппаратного адаптера используется WARP: на виртуальной машине без GPU (или с `WGPU_ADAPTER_NAME`/принудительным WARP) окно открывается и работает, в журнале запуска записан выбранный адаптер.
- [ ] U1-AC3 (FR-25). Окно без системной рамки 1200×800, минимум 720×560; шапка — заголовок окна: перетаскивание за пустое место, двойной клик разворачивает и восстанавливает, ресайз за края и углы; кнопки 46×44 «свернуть», «развернуть/восстановить» (иконка меняется), «закрыть» с красным фоном при наведении — как в UI v2.
- [x] U1-AC4. Цвета, радиусы и размеры обеих тем — Rust-константы, сгенерированные `build.rs` из `design/tokens.css`; тест сверяет набор переменных CSS и констант, ручных копий цветов в коде нет. Тема по умолчанию системная, переключатель Sun/Moon, выбор сохраняется.
- [x] U1-AC5. Шрифты IBM Plex Sans и Plex Mono и используемые иконки Lucide встроены в exe; кириллица, греческий (единицы измерения в ленте), глифы стрелок, `‹CR›`, `° ± ² µ` и `‹x2039›`/`‹x203A›` отображаются без «тофу». Plex Mono греческого не содержит (проверено по `cmap` всех пяти TTF), поэтому у моноширинных семейств запасной Plex Sans, а у средних и полужирных начертаний — обычный Plex Sans; тест глифов `the_fonts_have_every_glyph_the_interface_uses` сверяет все пять семейств по образцу с греческим (`fonts_mut` + `has_glyph`, плюс `MissingGlyphPolicy::Panic` харнесса), тест `a_feed_row_shows_greek_units_without_tofu` показывает строку ленты с UTF-8 «γ-GT μmol/L»: без запасного шрифта оба падают на `No glyph for "γ"`.
- [x] U1-AC6 (FR-31). Все строки интерфейса — через модуль i18n с каталогом `ru`; в коде экранов нет русских литералов (проверка тестом или линтом); ключи совпадают с каталогом, отсутствующий ключ — ошибка теста. Добавление `en` — новый каталог без правки экранов.
- [x] U1-AC7 (FR-30). Последние настройки и профили хранятся в `%APPDATA%\bytetap` (JSON); испорченный файл копируется в `settings.corrupt-<дата>.json`, приложение стартует с умолчаниями и показывает предупреждение. Unit-тесты: чтение, запись, порча, миграция отсутствующих полей.
- [x] U1-AC8 (NFR-3). Журнал запуска и panic hook перенесены из `diag.rs`: версия, ОС, адаптер wgpu, «интерфейс готов» после первого кадра; паника пишется в журнал запуска и показывает системное сообщение с путём к нему, процесс не закрывается молча.

Оценка WARP при этом подтверждается парой замеров подряд (разовая задержка — своп, пауза свёрнутого или перетаскиваемого окна — второго замера не получает и в цену не идёт), растёт не больше чем вдвое за кадр, тает ×7/8 на кадрах, которые выждали период целиком, но не ниже подтверждённой цены (без этого пола период сползал к 100 мс и запись на WARP в прогоне 39715728617 стоила 258 % одного ядра вместо 121 %), и сбрасывается после разворота, восстановления и свёртывания окна; промежуток, который ещё считается кадром, ограничен относительно ожидания (`live::max_gap` = 2 × ожидание + 250 мс). ## Удаление Tauri

Отдельный коммит после того, как владелец согласует снимки (U1-AC21) и пройдёт ручной смоук (U1-AC20): пока `app/` в дереве, UI v2 остаётся эталоном, а `main` до слияния `native-ui` собирает его. Всё, что можно подготовить заранее, подготовлено: `release.yml` собирает нативный exe (U1-AC29), документация, `README.md` и `CHANGELOG.md` описывают v0.2.0.

Удалить одним коммитом `chore!: drop the Tauri shell (U1-AC30)`:

- `app/` целиком: `app/src/**` (Vue), `app/src-tauri/**`, `app/package.json`, `app/index.html`, `app/vite.config.ts`, `app/tsconfig*.json`, `app/src/locales/**` — `git rm -r app`.
- Корневой `package.json`: `workspaces` → `["docs"]`; убрать скрипты `dev`, `build`, `tauri` и шаги `npm run check --workspace app` и `npm run test --workspace app` из `check`; `devDependencies` `esbuild` и `typescript` были нужны фронтенду; `overrides` `typescript` держался ради `vue-tsc`, для сайта остаётся только `vite`.
- `package-lock.json` пересобрать: `npm install --package-lock-only`, затем `npm ci` и `npm run docs:build` локально.
- `Cargo.toml`: member `app/src-tauri`; после этого `cargo update` оставляет `Cargo.lock` без `tauri`, `wry`, `webview2-com`, `tao`, `muda` и `tauri-plugin-*` — проверить `rg "name = \"(tauri|wry|webview2-com)\"" Cargo.lock`.
- `THIRD-PARTY-LICENSES.md` пересобрать: `node scripts/licenses.mjs` — граф `bytetap-app` меняется вместе с lock-файлом, иначе `licenses.mjs --check` в CI упадёт.
- `.github/workflows/ci.yml`: jobs `frontend` и `windows-app`; из `rust` — пакеты Tauri (`libwebkit2gtk-4.1-dev`, `libjavascriptcoregtk-4.1-dev`, `libsoup-3.0-dev`, `librsvg2-dev`, `libayatana-appindicator3-dev`), `mesa-vulkan-drivers` и `socat` остаются.
- `crates/bytetap-app/Cargo.toml`: `rfd` с `default-features = false, features = ["gtk3"]` → вариант по умолчанию (`xdg-portal`). `gtk3` был выбран только чтобы в workspace не оказалось двух систем диалогов рядом с Tauri, а вместе с `app/` уходит и пакет `libgtk-3-dev`.
- `docs/dev/testing.md`: ручной чек-лист v0.1.0 с WebView2 и уровни проверок `frontend`/`windows-app`; `docs/dev/architecture.md`: строки Tauri в таблице компонентов, ветки `v0.1.0` в потоке данных и в тестировании, раздел безопасности, дерево `app/`; `docs/dev/design.md`: `data-tauri-drag-region` и `@lucide/vue`; `docs/dev/requirements.md`: членство `app/src-tauri` в разделе «Технологии», если оно останется; `docs/dev/stages/M2.md` и `M3.md` остаются историей, но в них стоит пометить, что код удалён.
- `shared/control-chips.ts` остаётся: им пользуется пример обмена на сайте.

Проверить после удаления: `rg -i "tauri|wry|webview2"` по репозиторию (кроме `docs/dev/stages/**` и `CHANGELOG.md`), `cargo tree -p bytetap-app | rg -i "tauri|wry"` пусто, `npm run check`, `npm run docs:build`, `actionlint`, `zizmor`.
