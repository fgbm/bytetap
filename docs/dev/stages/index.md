# Этапы

План работ разбит на этапы M0–M6 и этап U1 (перенос интерфейса на egui между M3 и M4); состав каждого описан в [требованиях](/dev/requirements), порядок релизов — в [дорожной карте](/dev/roadmap). У каждого этапа есть файл с шагами и критериями приёмки.

- [M0 — каркас](/dev/stages/M0)
- [M1 — ядро: TCP-сервер, журнал, автоответчик HL7/MLLP](/dev/stages/M1)
- [M2 — интерфейс: настройки, старт/стоп, живая лента](/dev/stages/M2)
- [M3 — TCP-клиент, ASTM, «Авто», COM-порт](/dev/stages/M3)
- [U1 — нативный интерфейс (egui)](/dev/stages/U1) — закрыт 2026-10-22, выпущен в v0.2.0; четыре критерия (U1-AC22, U1-AC25…AC27) перенесены в [бэклог](/dev/backlog)

Этап U1 закрыт на релизе v0.2.0 (2026-10-22): владелец проверил приложение на ноутбуке с Windows 11 22000 — дословно «Я приложение проверил, да, все нормально вроде работает», то есть общая проверка exe v0.2.0, без прохода чек-листа по пунктам, — и ответил «Утвердить, закрыть U1»: визуальное соответствие утверждено, этап закрыт. Итоги — в [U1](/dev/stages/U1), открытые ручные проверки — в [бэклоге](/dev/backlog). Следующий этап — M4 (прокси TCP, v0.3.0).
