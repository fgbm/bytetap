# Дизайн-система

Дизайн-направление bytetap утверждено владельцем: инструмент инженера, а не витрина. Интерфейс выглядит как измерительный прибор — плотная сетка, моноширинные данные, цвет только там, где он несёт смысл. Значения живут в `design/tokens.css` — единственном источнике токенов для приложения и сайта документации; описание ниже объясняет, как их применять.

## Принципы

- Направление всегда обозначается цветом и стрелкой или иконкой Lucide. Один цвет без второго признака не используется: цвет не должен быть единственным носителем смысла.
- Автоответ (синтетические данные, `synthetic: true`) — штриховка 9% и метка с иконкой `bot`. Штриховка отличает ответ приложения от реального трафика ЛИС.
- Управляющие символы (`<STX>`, `<CR>`, `<x0B>` и т.п.) — плашки: моноширинный текст в рамке на фоне `ctrl-bg`.
- Фирменный элемент — двухдорожечная трасса над лентой: верхняя дорожка «анализатор → ЛИС», нижняя «ЛИС → анализатор». В светлой теме трасса светлая и лежит на `trace-bg`, в тёмной — как на экране осциллографа.
- Тема по умолчанию берётся из системы (`prefers-color-scheme`), переключатель темы — в панели приложения. Сайт переключает тему штатной кнопкой VitePress.

## Токены

Тема задаётся атрибутом `data-theme="light|dark"` на `<html>`; без атрибута действует системная тема. Системная тема вынесена в отдельный файл `design/tokens-system.css` — его подключает только приложение. Сайт этот файл не берёт: VitePress переводит системную тему в класс `dark` на `<html>`, поэтому в `design/tokens.css` тёмные значения продублированы селектором `html.dark` рядом с `[data-theme="dark"]`, и `@media (prefers-color-scheme: dark)` в сборку сайта не попадает.

При `prefers-reduced-motion: reduce` длительности обнуляются: оба токена становятся `0s`, анимации в интерфейсе отключаются без отдельной ветки в компонентах.

## Типографика

- Интерфейс — IBM Plex Sans, веса 400/500/600. Данные, время, HEX и управляющие символы — IBM Plex Mono 400/500.
- Основной кегль интерфейса 14px, данные в ленте — 12.5px, заголовки — 20px и 28px, подписи — 11–13px.
- Оба шрифта подключены локально пакетами `@fontsource/ibm-plex-sans` и `@fontsource/ibm-plex-mono` (кириллица и латиница) и попадают в сборку: ни приложение, ни сайт не запрашивают шрифты из сети.
- Числа в ленте — табличные (`font-variant-numeric: tabular-nums`), чтобы столбец времени не дёргался.

## Иконки

Иконки — пакет `@lucide/vue` (ISC), бандлится в сборку; самодельных SVG-иконок нет. Трасса `SignalTrace` — не иконка, а декоративный элемент из двух дорожек.

Базовый набор:

| Иконка | Где |
|--------|-----|
| `arrow-right` | направление «анализатор → ЛИС» |
| `arrow-left` | направление «ЛИС → анализатор» |
| `plug` | режимы TCP и COM |
| `circle-alert` | ошибки и предупреждения |
| `bot` | метка автоответа |
| `square` | кнопка «Стоп» |
| `server` | режим «вместо ЛИС» |
| `folder-open` | открыть папку журналов |
| `sun` / `moon` | переключатель темы |

## Контраст

Значения посчитаны по формуле WCAG 2.1 для фактических токенов. Порог для текста — 7:1 (AAA), для цветов направлений — 4.5:1 к фону.

| Пара | Светлая | Тёмная | Порог |
|------|---------|--------|-------|
| `text` к `surface-0` | 18.53 | 14.86 | ≥ 7 |
| `text` к `surface-1` / `trace-bg` | 17.28 | 13.91 | ≥ 7 |
| `text-muted` к `surface-0` | 5.65 | 5.35 | ≥ 7 |
| `text-muted` к `surface-1` / `trace-bg` | 5.27 | 5.00 | ≥ 7 |
| `dir-a2l` к `surface-0` | 5.17 | 11.14 | ≥ 4.5 |
| `dir-a2l` к `surface-1` / `trace-bg` | 4.83 | 10.43 | ≥ 4.5 |
| `dir-l2a` к `surface-0` | 5.02 | 10.62 | ≥ 4.5 |
| `dir-l2a` к `surface-1` / `trace-bg` | 4.68 | 9.94 | ≥ 4.5 |
| `ctrl` к `surface-0` | 8.13 | 9.21 | ≥ 7 |
| `ctrl` к `ctrl-bg` | 7.09 | 7.34 | ≥ 7 |
| `danger` к `surface-0` | 6.04 | 6.60 | ≥ 4.5 |
| `rec-fg` к `rec-bg` | 18.53 | 11.36 | ≥ 7 |
| `rec` к `surface-0` | 3.94 | 5.83 | ≥ 4.5 |

Цвета направлений проходят порог в обеих темах. `text-muted` до 7:1 не дотягивает (5.65 и 5.35 на основном фоне), но выше 4.5:1 и используется только для вторичных подписей; значение оставлено как утверждено. Красный `rec` в светлой теме даёт 3.94 к белому фону — ниже 4.5 для текста, но он применяется как заливка кнопки, а контраст подписи на ней 18.53.

## Где применяется

- Приложение: `app/src/main.ts` подключает `design/tokens.css`, `design/tokens-system.css` и шрифты, заглушка `App.vue` использует токены; тема — системная.
- Сайт: `docs/.vitepress/theme/` расширяет DefaultTheme, импортирует `design/tokens.css` (без системного файла) и мапит на переменные `--vp-*`; компоненты `ExchangeSample` и `SignalTrace` показывают пример обмена и фирменную трассу на главной.
