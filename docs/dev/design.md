# Дизайн-система

Дизайн-направление bytetap утверждено владельцем: инструмент инженера, а не витрина. Интерфейс выглядит как измерительный прибор — плотная сетка, моноширинные данные, цвет только там, где он несёт смысл. Значения живут в `design/tokens.css` — единственном источнике токенов для приложения и сайта документации; описание ниже объясняет, как их применять.

## Принципы UI v2

Владелец забраковал интерфейс M2 как «очень шумный» и утвердил направление UI v2 (2026-10-19). Правила ниже действуют для приложения; макет M2 `docs/public/mockups/m2-main.html` оставлен как история и эталоном больше не считается — его заменили эта UI-спецификация и скриншоты в `docs/dev/stages/M3.md`.

- Тишина. Минимум рамок, плашек и заливок: границы — тонкая линия `border`, выделение — фон `hover`. Служебное (профили, папка журналов, комментарий, интерфейс, поток COM) живёт в свёрнутом «Дополнительно» или в меню «…», а не на экране.
- Одна шапка. Шапка приложения — это одновременно заголовок окна и единственная строка состояния: бренд, действие, сводка режима, счётчики, меню. Второго ряда, отдельной строки состояния и чипов нет.
- Окно без системной рамки. `decorations: false`, `shadow: true`; пустые области шапки помечены `data-tauri-drag-region` (перетаскивание, двойной клик — развернуть), справа кнопки окна как в Windows: 46px шириной во всю высоту шапки 44px, крестик при наведении — `--bt-window-close` с белой иконкой.
- Сценарии вместо переключателя режимов. Стартовый экран спрашивает, как анализатор связан с ноутбуком, и предлагает три карточки: анализатор подключается ко мне (TCP-сервер), я подключаюсь к анализатору (TCP-клиент), кабель COM-порта. Несуществующие режимы (прокси, прослушка COM) не показываются вовсе, а не «неактивны с пометкой версии».
- Направление всегда обозначается цветом и стрелкой. Один цвет без второго признака не используется: в ленте это глиф `→`/`←`, на трассе — отдельная дорожка.
- Управляющие символы — глифы, а не плашки: `‹CR›`, `‹STX›`, `‹x0B›` цветом `ctrl` с прозрачностью 0.55 и кеглем 11px, без фона. В HEX-дампе управляющие байты выделены только цветом.
- Автоответ (синтетические данные, `synthetic: true`) — слово «автоответ» в конце строки цветом `dir-l2a`, без штриховки и полосы: строку видно по слову, а не по узору.
- Фирменный элемент — двухдорожечная трасса над лентой: верхняя дорожка «анализатор → ЛИС», нижняя «ЛИС → анализатор», дорожки по 26px, импульсы-столбики 2px высотой по логарифму длины, подпись-глиф `→`/`←` слева. Трасса — график, а не иконка. В светлой теме она лежит на `trace-bg`, в тёмной — как на экране осциллографа. При просмотре журнала трасса становится картой всей сессии в тонкой рамке.
- Автопрокрутка без кнопки: при прокрутке вверх лента стоит, а внизу справа появляется тёмная таблетка «↓ N новых»; клик возвращает вниз и включает догон.
- Ошибки — текстом у поля (12px, `danger`), а не баннером. Отказ журнала — одна строка под шапкой с двумя текстовыми действиями. Ошибок-иллюстраций и модальных диалогов нет, кроме ввода комментария.
- Тема по умолчанию берётся из системы (`prefers-color-scheme`), переключатель Sun/Moon — в шапке; он показывает тему, в которую переведёт. Сайт переключает тему штатной кнопкой VitePress.

## Токены

Тема задаётся атрибутом `data-theme="light|dark"` на `<html>`; без атрибута действует системная тема. Системная тема вынесена в отдельный файл `design/tokens-system.css` — его подключает только приложение. Сайт этот файл не берёт: VitePress переводит системную тему в класс `dark` на `<html>`, поэтому в `design/tokens.css` тёмные значения продублированы селектором `html.dark` рядом с `[data-theme="dark"]`, и `@media (prefers-color-scheme: dark)` в сборку сайта не попадает.

## Типографика

- Интерфейс — IBM Plex Sans, веса 400/500/600. Данные, время, HEX и управляющие символы — IBM Plex Mono 400/500.
- Основной кегль интерфейса 14px, данные в ленте — 12.5px, заголовок сценария — 18px/600, вопрос стартового экрана — 13px `muted`, подписи полей — 12px `muted`, адрес для анализатора — 28px IBM Plex Mono.
- Оба шрифта подключены локально пакетами `@fontsource/ibm-plex-sans` и `@fontsource/ibm-plex-mono` (кириллица и латиница) и попадают в сборку: ни приложение, ни сайт не запрашивают шрифты из сети.
- Числа в ленте — табличные (`font-variant-numeric: tabular-nums`), чтобы столбец времени не дёргался.

## Иконки

Иконки — пакет `@lucide/vue` (ISC), бандлится в сборку; самодельных SVG-иконок и иллюстраций нет. Трасса `TraceView` — не иконка, а декоративный график из двух дорожек; направления в ленте обозначены глифами `→`/`←` моноширинным шрифтом, а не иконками.

Базовый набор:

| Иконка | Где |
|--------|-----|
| `monitor-down` | сценарий «Анализатор подключается ко мне» |
| `network` | сценарий «Я подключаюсь к анализатору» |
| `usb` | сценарий «Кабель COM-порта» |
| `chevron-right` / `chevron-down` | шеврон карточки и «Дополнительно» |
| `folder-open` | меню «Журналы» |
| `sun` / `moon` | переключатель темы |
| `more-horizontal` | меню «…» в шапке записи |
| `minus`, `square`, `copy`, `x` | кнопки окна: свернуть, развернуть, восстановить, закрыть |
| `arrow-left` | «← Сценарии» |
| `copy` | копирование адреса |
| `refresh-cw` | обновление списка портов |
| `pen` | комментарий к журналу |
| `triangle-alert` | персональные данные в просмотре журнала |
| `circle-alert` | отказ журнала |
| `arrow-down` | таблетка «↓ N новых» |

## Контраст

Значения посчитаны по формуле WCAG 2.1 для фактических токенов. Порог для текста — 7:1 (AAA), для цветов направлений — 4.5:1 к фону.

| Пара | Светлая | Тёмная | Порог |
|------|---------|--------|-------|
| `text` к `surface-0` | 18.53 | 14.86 | ≥ 7 |
| `text` к `surface-1` / `trace-bg` | 17.28 | 13.91 | ≥ 7 |
| `text` к `hover` | 16.65 | 13.37 | ≥ 7 |
| `text-muted` к `surface-0` | 5.65 | 5.35 | ≥ 7 |
| `text-muted` к `surface-1` / `trace-bg` | 5.27 | 5.00 | ≥ 7 |
| `text-faint` к `surface-0` | 3.12 | 3.21 | ≥ 4.5 |
| `text-faint` к `trace-bg` | 2.91 | 3.27 | ≥ 4.5 |
| `dir-a2l` к `surface-0` | 5.17 | 11.14 | ≥ 4.5 |
| `dir-a2l` к `surface-1` / `trace-bg` | 4.83 | 10.43 | ≥ 4.5 |
| `dir-l2a` к `surface-0` | 5.02 | 10.62 | ≥ 4.5 |
| `dir-l2a` к `surface-1` / `trace-bg` | 4.68 | 9.94 | ≥ 4.5 |
| `ctrl` к `surface-0` | 8.13 | 9.21 | ≥ 7 |
| `ctrl` к `ctrl-bg` | 7.09 | 7.34 | ≥ 7 |
| `danger` к `surface-0` | 6.04 | 6.60 | ≥ 4.5 |
| `rec-fg` к `rec-bg` | 18.53 | 11.36 | ≥ 7 |
| `rec` к `surface-0` | 3.94 | 5.83 | ≥ 4.5 |
| `surface-0` к `window-close` | 5.66 | 5.66 | ≥ 4.5 |

Цвета направлений проходят порог в обеих темах. `text-muted` до 7:1 не дотягивает (5.65 и 5.35 на основном фоне), но выше 4.5:1 и используется только для вторичных подписей; значение оставлено как утверждено. Красный `rec` в светлой теме даёт 3.94 к белому фону — ниже 4.5 для текста, но он применяется как заливка кнопки, а контраст подписи на ней 18.53. `text-faint` (muted-2) ниже 4.5 в обеих темах: владелец выбрал эти значения для времени, номера соединения и метаданных записей — это не основной текст, а служебная разметка строки; значение зафиксировано в токене, чтобы его можно было поднять одним изменением, если владелец пересмотрит решение.

## Где применяется

- Приложение: `app/src/main.ts` подключает `design/tokens.css`, `design/tokens-system.css` и шрифты; общие примитивы (шапка-заголовок, меню, карточки сценариев, поля, лента) — в `app/src/styles/app.css`, компоненты держат только раскладку. Тема — системная по умолчанию, переключатель Sun/Moon в шапке.
- Сайт: `docs/.vitepress/theme/` расширяет DefaultTheme, импортирует `design/tokens.css` (без системного файла) и мапит на переменные `--vp-*`; компоненты `ExchangeSample` и `SignalTrace` показывают пример обмена и фирменную трассу на главной в том же виде, что UI v2: глифы `‹CR›` без фона, слово «автоответ» в конце строки и столбики трассы высотой по длине фрагмента.
