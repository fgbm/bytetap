# Дорожная карта

План релизов проекта. Источник требований — [requirements.md](requirements.md), границы MVP и порядок этапов — раздел 13 того же файла. План ближайшего этапа — [stages/M0.md](stages/M0.md).

| Релиз | Этапы | Состав |
|-------|-------|--------|
| v0.1.0 (MVP) | M0–M3 | Каркас и CI; ядро с журналом и автоответчиком HL7/MLLP; интерфейс; TCP-клиент, автоответчик ASTM, режим «Авто», RS232 «вместо ЛИС» |
| v0.2.0 | M4 | Прокси TCP: запись обмена при работающей ЛИС |
| v0.3.0 | M5 | Прослушка двух COM-портов |
| v0.4 и далее | M6 | Подпись кода и установщик; дополнительно FR-13, экспорт в pcapng, разбор сообщений до полей |

Состав MVP подробно: v0.1.0 — это переносимый exe без подписи, покрывающий TCP-сервер, TCP-клиент, режим «вместо ЛИС» через COM, автоответчики MLLP, ASTM и «Авто», журнал, интерфейс и сайт с инструкцией.
