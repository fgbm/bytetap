# WebView2

Интерфейс bytetap — это WebView2, компонент Microsoft Edge, который используют многие настольные программы. На Windows 11 и на обновлённой Windows 10 он уже установлен; на старых или урезанных сборках его нет.

Если компонента нет, bytetap до создания окна показывает системное сообщение «Для работы bytetap нужен компонент Microsoft Edge WebView2…» и закрывается. Это не ошибка сборки: без WebView2 интерфейсу негде рисоваться.

Что делать:

1. Скачайте **Evergreen Bootstrapper** или **Evergreen Standalone Installer** со страницы Microsoft: <https://developer.microsoft.com/microsoft-edge/webview2/>. Для машины без интернета нужен автономный установщик — его можно принести на флешке.
2. Установите компонент (права администратора обычно нужны; на некоторых сборках установка идёт в профиль пользователя).
3. Запустите bytetap снова.

Без прав администратора и без установки остаётся консольная версия `bytetap-cli` — она не использует WebView2: [Запуск из командной строки](/guide/cli). Запись при этом полноценная, отличается только способ управления.
