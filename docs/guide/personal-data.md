# Персональные данные

Журнал bytetap — это «сырой» обмен между анализатором и ЛИС. В нём могут оказаться фамилия, имя и отчество пациента, дата рождения, номер пробы и идентификаторы, по которым человека можно узнать. Программа их не распознаёт и не обезличивает: это делает человек перед тем, как использовать журнал в тестах, отчётах или переписке.

Правила простые:

- Журналы хранятся только на компьютере, где шла запись. bytetap ничего не отправляет в сеть, кроме трафика самой сессии: ни телеметрии, ни автообновлений, ни загрузки журналов.
- В интерфейсе на экране журнала всегда видно предупреждение: «Журнал может содержать персональные данные пациентов. Не публикуйте и не пересылайте его без обезличивания».
- Перед отправкой журнала разработчику, в поддержку или в issue обезличьте его: замените ФИО, даты рождения, номера проб и всё, что указывает на пациента, на синтетические значения. Сдвигать время и менять кодировки не нужно — они не идентифицируют человека.
- Не кладите журналы в общие папки, облачные диски и мессенджеры. Папка журналов по умолчанию — `%USERPROFILE%\Documents\bytetap`; программа предупреждает, если папка лежит в OneDrive или на сетевом диске.
- Ненужные журналы удаляйте: файл живёт, пока вы его не удалите.

Для воспроизведения проблемы обычно достаточно короткого фрагмента без данных пациента: заголовок сессии, `open`, несколько `data` с заменёнными значениями и `close`. В репозитории проекта журналы реальных сессий не хранятся — только синтетические фикстуры.

Ответственность за обработку персональных данных лежит на организации, которая ведёт запись: bytetap — инструмент, а не средство анонимизации.
