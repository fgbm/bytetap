# Установка

bytetap — один исполняемый файл `bytetap.exe` без установщика: скачайте архив из раздела [Releases](https://github.com/fgbm/bytetap/releases), распакуйте и положите `bytetap.exe` в постоянную папку, например `C:\Tools\bytetap`. Установка в систему, служба и права администратора не нужны: программа пишет журналы рядом с документами пользователя.

Что понадобится на компьютере:

- Windows 10 или 11, 64-битная;
- компонент Microsoft Edge WebView2 — на актуальных Windows он уже есть, на старых его нужно доустановить: [WebView2](/guide/webview2);
- свободное место под журналы: один фрагмент HL7 занимает сотни байт, насыщенная смена — десятки мегабайт.

Первый запуск скачанного файла Windows встречает предупреждением SmartScreen: сборка не подписана платным сертификатом. Что нажать — [SmartScreen и антивирусы](/guide/smartscreen). Дальше — [Первый запуск](/guide/first-run).

В архив релиза входит только интерфейс `bytetap.exe` и файлы `README.md`/`LICENSE`. Консольная версия `bytetap-cli` собирается из исходников (`cargo build --release -p bytetap-cli`) и описана на странице [Запуск из командной строки](/guide/cli).

Проверить целостность архива можно по файлу `SHA256SUMS` из релиза:

```powershell
Get-FileHash .\bytetap-v0.1.0-windows-x64.zip -Algorithm SHA256
```

Хеш должен совпасть со строкой в `SHA256SUMS`.
