# Установка

bytetap — один исполняемый файл `bytetap.exe` без установщика: скачайте архив из раздела [Releases](https://github.com/fgbm/bytetap/releases), распакуйте и положите `bytetap.exe` в постоянную папку, например `C:\Tools\bytetap`. Установка в систему, служба и права администратора не нужны: программа пишет журналы рядом с документами пользователя. Текущая версия — 0.2.0.

Что понадобится на компьютере:

- Windows 10 (1809 или новее) или Windows 11, 64-битная;
- видеодрайвер не нужен: без аппаратного ускорения окно рисует программный растр WARP, который входит в Windows;
- свободное место под журналы: один фрагмент HL7 занимает сотни байт, насыщенная смена — десятки мегабайт.

Других компонентов нет: WebView2, .NET и Visual C++ Redistributable не нужны — `bytetap.exe` зависит только от системных DLL Windows. Рядом с exe в архиве лежат `README.md`, `LICENSE` и `THIRD-PARTY-LICENSES.md`.

Первый запуск скачанного файла Windows встречает предупреждением SmartScreen: сборка не подписана платным сертификатом. Что нажать — [SmartScreen и антивирусы](/guide/smartscreen). Дальше — [Первый запуск](/guide/first-run).

Консольная версия `bytetap-cli` собирается из исходников (`cargo build --release -p bytetap-cli`) и описана на странице [Запуск из командной строки](/guide/cli).

Проверить целостность архива можно по файлу `SHA256SUMS` из релиза:

```powershell
Get-FileHash .\bytetap-v0.2.0-windows-x64.zip -Algorithm SHA256
```

Хеш должен совпасть со строкой в `SHA256SUMS`.
