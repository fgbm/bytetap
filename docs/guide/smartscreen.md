# SmartScreen и антивирусы

`bytetap.exe` не подписан сертификатом подписи кода: проект независимый и открытый, платный сертификат в бюджет не входит. Поэтому Windows SmartScreen при первом запуске скачанного файла показывает «Windows защитила Ваш компьютер».

Как запустить:

1. Нажмите «Подробнее» в окне предупреждения.
2. Нажмите «Выполнить в любом случае».

Это разовое действие для этого файла: после запуска SmartScreen его больше не показывает, пока файл не заменят новой версией.

Что стоит знать:

- Предупреждение появляется из-за отсутствия подписи, а не из-за найденной угрозы. Файл можно сверить с `SHA256SUMS` из релиза (см. [Установка](/guide/install)).
- Антивирус может ругаться на неподписанный exe, который слушает TCP-порт: это поведение похоже на «сервер». Программу можно добавить в исключения; исходный код и сборка в GitHub Actions открыты.
- Права администратора не нужны ни для запуска, ни для обхода SmartScreen: предупреждение снимается текущим пользователем.
- Если политика организации запрещает запуск неподписанных программ, а подписи нет, спросите администратора — обхода на стороне пользователя не будет.
