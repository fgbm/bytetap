# bytetap

Настольное приложение для записи «сырого» обмена между лабораторным анализатором и ЛИС: HL7/MLLP, ASTM и собственные протоколы производителей по TCP/IP и RS232. Журнал сессии с точными байтами и метками времени нужен разработчику драйвера анализатора.

Статус: проектирование. Требования — [docs/requirements.md](docs/requirements.md).

## Режимы

- **Вместо ЛИС** — bytetap принимает данные от анализатора по TCP (сервер или клиент) или COM-порту и отвечает базовыми подтверждениями (HL7 ACK, ASTM ACK).
- **Прокси** — bytetap стоит между анализатором и ЛИС и записывает обе стороны, не меняя данных.
- **Прослушка RS232** — два COM-порта, пересылка в обе стороны с записью.

## Персональные данные

Журналы сессий могут содержать персональные данные пациентов. Они хранятся только локально; перед публикацией или передачей их нужно обезличить вручную.

## Стек

Rust (tokio), Tauri v2, Vue 3 + TypeScript.
