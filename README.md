# bytetap

bytetap — настольное приложение для записи «сырого» обмена между лабораторным анализатором и ЛИС: HL7/MLLP, ASTM E1381/E1394 и собственные протоколы производителей по TCP/IP и RS232. Журнал сессии с точными байтами и метками времени нужен разработчику драйвера анализатора.

Статус: в разработке, первый релиз — v0.1.0. Требования — [на сайте документации](https://fgbm.github.io/bytetap/dev/requirements).

## Персональные данные

Журналы сессий могут содержать персональные данные пациентов: ФИО, даты рождения, идентификаторы. Приложение их не обезличивает. Журналы хранятся только локально и никуда не отправляются; перед публикацией или передачей их нужно обезличить вручную.
