# bytetap

bytetap — настольное приложение для записи «сырого» обмена между лабораторным анализатором и ЛИС: HL7/MLLP, ASTM E1381 и собственные протоколы производителей по TCP/IP и RS232. Журнал сессии с точными байтами и метками времени нужен разработчику драйвера анализатора.

Статус: **v0.1.0 — первый релиз**. Что уже умеет:

- три сценария подключения: анализатор подключается к ноутбуку, bytetap подключается к анализатору, кабель COM-порта вместо ЛИС;
- автоответчики HL7/MLLP, ASTM E1381 и «Авто» — определение протокола по первому значимому байту;
- живую ленту обмена в виде текста или HEX с кодировками и фильтром соединений;
- журнал в JSONL с заголовком сессии, комментариями и просмотром записи в приложении;
- консольную версию `bytetap-cli` для записи без окна, проверки журнала и списка COM-портов.

## Требования

Windows 10 или 11, 64-битная, и компонент [Microsoft Edge WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) (на актуальных Windows уже установлен). Права администратора не нужны. Сборка не подписана, поэтому первый запуск встречает SmartScreen: [как запустить](https://fgbm.github.io/bytetap/guide/smartscreen).

## Персональные данные

Журналы сессий могут содержать персональные данные пациентов: ФИО, даты рождения, идентификаторы. Приложение их не обезличивает. Журналы хранятся только локально и никуда не отправляются; перед публикацией или передачей их нужно обезличить вручную. Подробнее — [Персональные данные](https://fgbm.github.io/bytetap/guide/personal-data).
